How saving works

Save draft keeps edits on this device. Download changes creates a ZIP you can send to ChatGPT. Publish commits your changes to your GitHub repository and starts automatic publishing.

Only someone with write access to your repository can publish. Opening this editor does not let a visitor change your live site.

ONE-TIME SETUP PER SESSION

Publish with your GitHub account

The editor needs permission to save files to varnaresh17.github.io. The GitHub connection in ChatGPT is separate.

  1. Create a fine-grained GitHub token ↗
  2. Select Only select repositories → varnaresh17.github.io.
  3. Under repository permissions, set Contents → Read and write, then generate the token.
  4. Paste it below. Do not send it in chat.

The token is held only in this tab’s memory. It is never saved in drafts or website files, and is sent only to GitHub’s API. Closing this tab disconnects publishing.

    Connect your private statistics

    Your key is sent only to your GoatCounter account. By default it stays in this tab’s memory. You can optionally remember it on your personal device below. No key or statistics are published to GitHub or website files.

    Optional: saves your read-only key in this browser, so the dashboard reconnects automatically. Anyone using this browser profile, and scripts running on this website, can access the saved key. Use only on your own trusted device. “Forget this device” removes it.

    One-time setup: create a read-only key
    1. Open your GoatCounter account.
    2. Choose your username in the top menu, then API, and create a key named Website statistics with permission to read statistics only.
    3. Copy the key into the field above. Do not paste it into chat, GitHub files or a public page.
    4. Keep the GoatCounter dashboard private and leave public visitor counts disabled.

    Create the key only once and reuse it. Select “Remember on this device” to reconnect automatically for up to 30 days. Without it, enter the same key again each session. You never need to create a new token for each visit.
