ONE-TIME SETUP PER SESSION

Publish with your GitHub account

The editor needs permission to save files to varnaresh17.github.io. The GitHub connection in ChatGPT is separate.

  1. Create a fine-grained GitHub token ↗
  2. Select Only select repositories → varnaresh17.github.io.
  3. Under repository permissions, set Contents → Read and write, then generate the token.
  4. Paste it below. Do not send it in chat.

The token is held only in this tab’s memory. It is never saved in drafts or website files, and is sent only to GitHub’s API. Closing this tab disconnects publishing.
